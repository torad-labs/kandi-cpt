01

Parametric — where training landed

For every parameter, the fraction that moved between stages: ‖Δ‖ / ‖W‖, per layer and per module. This localizes the footprint — and answers whether CPT installed knowledge (large, structured) while SFT merely elicited it (small, surgical).

02

Representational — basins separating

Confusable entities (stages, days) start collapsed into one region of activation space and should fan into distinct basins after CPT. Cosine-separation is a noisy proxy — the trustworthy signals are p@1 (retrieval beats chance) and the day-probe (a linear classifier reads day off the representation). The morph is driven by the measured p@1.

03

Behavioral — the success gate

145 deterministic probes per run: real venue facts it should answer, and provably non-existent editions it must abstain on. Greedy decoding, rule-based scoring. A run PASSES only if it threads the needle — low fabrication, accurate when it answers, and not degenerately abstaining on everything.

Instruments: weight_delta.py (parametric) · geometry_probe (representational) · eval_sft_calibration.py (behavioral). Each emits a *_data.js; this page is static. Deterministic by construction — fixed seeded probes, greedy decoding, rule-based classification.
