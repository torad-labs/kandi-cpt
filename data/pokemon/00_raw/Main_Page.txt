Message from the Editor
April 16
Bulbapedia has a new look!
Yesterday we launched BulbaVector, the biggest skin refresh on
Bulbapedia
since we first launched a mobile-friendly skin over a decade ago. With the launch of this skin, both desktop and mobile users will be served by the same skin, which should hopefully deliver a more unified experience for everyone.
Just to give you all a bit of background on why this is happening... When we first launched a mobile-friendly skin, we did so using an m-dot mobile specific subdomain, which at the time was the standard on many other large websites. That subdomain was implemented via the MobileFrontend extension for
MediaWiki
, which was also in use on
Wikipedia
. This setup allowed search engines to serve mobile users with the mobile URL instead of the "canonical" main URL. As of early 2024, however, the classic m-dot mobile subdomains stopped being supported by major search engines. Whereas previously we could have separate skins for desktop and mobile users, search engines now expected that websites support both from the same URL, with a responsive design. Some search engines also began actively penalizing websites without responsive layouts in their search results.
The new BulbaVector skin is built off of the same Vector 2022 skin that has been the default Wikipedia interface since 2023, and is also in use on many other wikis across the internet. It's a solid base that's seen lots of support and continuing development from the wider MediaWiki community, and long-term it should mean a much smoother experience for everyone, both in terms of you using the site, and for us in maintaining things at the backend.
For all of our editors who might prefer the old skins though, don't worry, they're not going away. When you next log in, you'll still be on whatever skin you had selected before we flipped the switch on BulbaVector, and they'll always remain an option available in
your account preferences
. We do hope you'll give BulbaVector a whirl though - and let us know what you think!
As with any major change like this, we have had a few teething issues that we're sorting out. If you do notice anything amiss, we'd greatly appreciate it if you'd hop into the
Bulbagarden Discord server
and let us know in the Bulbapedia
#templates-css-tech
channel. For users on mobile specifically, if you aren't seeing the mobile version of the skin please make sure your web browser isn't set to request a desktop site, or disable this setting if you prefer the desktop view. If you're logged in, make sure that "Enable responsive mode" is also ticked in your preferences.
That's all for now, and as always, happy editing!
Landfish7
Co-Deputy Editor-in-Chief, Bulbapedia
